# UltraVNC Viewer 整体架构设计文档

## 1. 项目概述

UltraVNC Viewer 是一个功能完整的 VNC（Virtual Network Computing）客户端实现，用于远程桌面连接和控制。该客户端采用 C++ 语言开发，基于 Windows 平台，支持多种编码方式、安全认证和扩展功能。

### 1.1 项目位置
```
vncviewer/
├── 核心连接模块 (ClientConnection*.cpp/h)
├── 应用程序模块 (VNCviewerApp*.cpp/h, main.cpp)
├── 用户界面模块 (SessionDialog*.cpp/h, VNCOptions.cpp/h)
├── 文件传输模块 (FileTransfer.cpp/h)
├── 文本聊天模块 (TextChat.cpp/h)
├── 键盘映射模块 (KeyMap*.cpp/h)
├── DirectX 渲染模块 (directx/)
├── 资源文件 (res/)
└── Qt版本 (vncviewerqt.cpp/h, main.cpp)
```

### 1.2 技术特点
- **多平台渲染**: 支持 GDI 和 DirectX 两种渲染方式
- **多编码支持**: Raw, RRE, Hextile, Zlib, Tight, Ultra, Ultra2 等多种编码
- **安全认证**: 支持 VNC 认证、MS-Logon I/II/III、TLS、VeNCrypt、RSAAES 等
- **扩展功能**: 文件传输、文本聊天、剪贴板同步
- **插件系统**: DSM Plugin 支持数据流加密

### 7.2 编码器扩展

新增编码器只需：
1. 在 `rfb.h` 中定义新的编码类型常量
2. 创建 `ClientConnectionXXX.cpp` 实现解码逻辑
3. 在 `ClientConnection::ReadScreenUpdate()` 中添加处理分支
4. 在 `VNCOptions` 中添加编码选项

## 9. 总结

UltraVNC Viewer 采用了分层架构设计，主要特点：

1. **模块化设计**: 各功能模块独立，便于维护和扩展
2. **多线程处理**: 网络 I/O 与 UI 分离，保证响应性
3. **编码器可扩展**: 支持多种编码格式，易于添加新编码
4. **安全机制完善**: 支持多种认证方式和数据加密
5. **跨平台考虑**: 同时支持 Win32 原生和 Qt 框架

该架构设计具有良好的可扩展性和可维护性，适合作为远程桌面客户端的参考实现。
