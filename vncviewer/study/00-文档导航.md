## 技术栈总结

### 核心技术
- **语言**: C++ (部分C)
- **UI框架**: Win32 API + Qt (可选)
- **网络**: Winsock 2
- **多线程**: omni_thread
- **加密**: CryptoAPI, libtls

### 第三方库
- **zlib**: 数据压缩
- **libjpeg-turbo**: JPEG图像处理
- **zstd**: 高性能压缩
- **LZO**: 快速压缩
- **omnithread**: 跨平台线程库

### 编译环境
- Visual Studio 2019+
- Windows SDK 10
- DirectX 9 SDK
- vcpkg 包管理器

## 常见问题解答

### Q1: 如何添加新的编码方式？
A: 参考03-编码解码系统详解文档，需要：
1. 在rfbproto.h中定义新的编码常量
2. 创建ClientConnectionXXX.cpp实现解码
3. 在ReadScreenUpdate中添加处理分支
4. 更新VNCOptions支持新编码

### Q2: 如何实现自定义认证？
A: 通过DSM插件系统：
1. 实现IPlugin接口
2. 编写Transform/Restore函数
3. 配置使用插件

### Q3: 如何优化传输性能？
A: 根据网络条件：
1. 高速网络：使用Ultra/Ultra2编码
2. 中速网络：使用Tight/ZRLE编码
3. 低速网络：启用压缩，降低色深

### Q4: 如何调试连接问题？
A: 使用日志系统：
1. 设置日志级别
2. 启用文件日志
3. 分析连接流程
4. 检查协议协商
