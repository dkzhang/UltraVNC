# UltraVNC Viewer 安全认证系统详解

## 1. 安全认证概述

UltraVNC Viewer 实现了多层次的安全认证体系，支持从传统的 VNC 密码认证到现代的 RSA-AES 加密认证，以满足不同安全级别的需求。

### 1.1 支持的认证类型

| 认证类型 | 定义常量 | 安全级别 | 特点 |
|---------|---------|---------|------|
| None | rfbSecTypeNone | 低 | 无认证，直接连接 |
| VNC Auth | rfbSecTypeVncAuth | 中 | 传统VNC密码认证，DES加密 |
| MS-Logon I | rfbSecTypeMsLogonI | 中 | Windows用户认证（旧版） |
| MS-Logon II | rfbSecTypeMsLogonII | 中-高 | Windows用户认证（改进版） |
| MS-Logon III | rfbSecTypeMsLogonIII | 高 | X25519 + AES-256-GCM |
| TLS | rfbSecTypeTLS | 高 | TLS/SSL加密传输 |
| VeNCrypt | rfbSecTypeVeNCrypt | 高 | VeNCrypt扩展认证 |
| RSA-AES | rfbSecTypeRSAAES | 很高 | RSA密钥交换 + AES加密 |

## 2. VNC 传统认证

### 2.1 认证流程

```
└────┬─────┘                                         └────┬─────┘
     │                                                    │

     │                                                    │
     │  ◀────── Authentication Result ──────────────────  │
     │           (成功/失败)                               │
     │                                                    │
```

### 2.2 DES 加密实现

VNC 使用 DES 算法加密挑战响应，但有一个特殊处理：密钥反转。

#### 加密函数（vncauth.c）

```c
/*
 * vncEncryptBytes - 加密挑战字节
 * 使用密码作为密钥（最多8字节）
 * VNC特殊的密钥处理：每个字节内部位反转
 */
void vncEncryptBytes(unsigned char *bytes, char *passwd)
{
    unsigned char key[8];
    unsigned int i;
    
    /* 使用密码构造密钥 */
    for (i = 0; i < MAXPWLEN && passwd[i]; i++) {
        key[i] = passwd[i];
    }
    for (; i < 8; i++) {
        key[i] = 0;
    }
    
    /* VNC特殊的位反转处理
     * DES标准要求密钥的每一位按顺序使用
     * 但VNC为了简化，对每个字节进行了位反转
     * 这使得实际使用的密钥与输入密码不同
     */
    for (i = 0; i < 8; i++) {
        key[i] = reverseByte(key[i]);
    }
    
    /* DES加密 */
    deskey(key, EN0);  // 设置加密密钥
    for (i = 0; i < CHALLENGESIZE; i += 8) {
        des(bytes + i, bytes + i);  // 加密8字节块
    }
}

/* 字节位反转函数 */
static unsigned char reverseByte(unsigned char b)
{
    unsigned char result = 0;
    for (int i = 0; i < 8; i++) {
        result |= ((b >> i) & 1) << (7 - i);
    }
    return result;
}
```

#### MS-Logon 扩展认证（64字节挑战）

```c
/*
 * vncEncryptPasswdMs - MS-Logon认证密码加密
 * 使用64字节挑战（而非标准的16字节）
 */
void vncEncryptPasswdMs(unsigned char *encryptedPasswd, char *passwd)
{
    unsigned char key[8];
    unsigned int i;
    
    /* 构造8字节密钥 */
    for (i = 0; i < MAXPWLEN && passwd[i]; i++) {
        key[i] = passwd[i];
    }
    for (; i < 8; i++) {
        key[i] = 0;
    }
    
    /* VNC特殊位反转 */
    for (i = 0; i < 8; i++) {
        key[i] = reverseByte(key[i]);
    }
    
    /* DES加密64字节 */
    deskey(key, EN0);
    for (i = 0; i < CHALLENGESIZEMS; i += 8) {
        des(encryptedPasswd + i, encryptedPasswd + i);
    }
}
```

### 2.3 安全性分析

#### 弱点
1. **密码长度限制**：最多8字节，容易暴力破解
2. **DES算法**：56位密钥已被认为不安全
3. **无前向保密**：密码泄露后历史通信可被解密
4. **重放攻击**：虽然使用随机挑战，但无时间戳防护

#### 实现细节
```cpp
void ClientConnection::AuthVnc()
{
    // 接收服务器挑战
    CARD8 challenge[CHALLENGESIZE];
    ReadExact((char*)challenge, CHALLENGESIZE);
    
    // 获取用户密码
    AuthDialog authDlg;
    int result = authDlg.DoDialog(dtPass, m_host, m_port);
    if (result != IDOK) {
        throw UserCancelExc();
    }
    
    // 加密挑战
    char* password = authDlg.m_passwd;
    vncEncryptBytes(challenge, password);
    
    // 发送加密响应
    WriteExact((char*)challenge, CHALLENGESIZE);
    
    // 接收认证结果
    CARD32 authResult;
    ReadExact((char*)&authResult, sizeof(authResult));
    authResult = Swap32IfLE(authResult);
    
    if (authResult != 0) {
        throw AuthenticationExc("VNC authentication failed");
    }
}
```

## 3. MS-Logon 认证系统

### 3.1 MS-Logon I（传统版本）

#### 认证流程
```

│  Client  │                                         │  Server  │
└────┬─────┘                                         └────┬─────┘
     │                                                    │
     │  ◀────── Challenge (64 bytes) ─────────────────   │
     │                                                    │
     │  ────── Response (DES encrypted) ───────────────▶  │
     │         包含用户名和密码                              │
     │                                                    │
     │  ◀────── Authentication Result ──────────────────  │
     │                                                    │
```

#### 实现代码

```cpp
void ClientConnection::AuthMsLogonI()
{
    // 接收64字节挑战
    CARD8 challenge[CHALLENGESIZEMS];
    ReadExact((char*)challenge, CHALLENGESIZEMS);
    
    // 获取用户名、密码、域
    AuthDialog authDlg;
    authDlg.DoDialog(dtUserPassNotEncryption, m_host, m_port);
    
    // 准备认证数据
    char response[256];
    memset(response, 0, sizeof(response));
    strncpy(response, authDlg.m_user, 256);
    strncpy(response + 64, authDlg.m_domain, 256);
    strncpy(response + 128, authDlg.m_passwd, 256);
    
    // 使用DES加密响应（使用密码作为密钥）
    vncEncryptPasswdMs((unsigned char*)response, authDlg.m_passwd);
    
    // 发送响应
    WriteExact(response, sizeof(response));
    
    // 验证结果
    CARD32 authResult;
    ReadExact((char*)&authResult, sizeof(authResult));
    
    if (Swap32IfLE(authResult) != 0) {
        throw AuthenticationExc("MS-Logon I authentication failed");
    }
}
```

### 3.2 MS-Logon II（改进版本）

MS-Logon II 使用 Diffie-Hellman 密钥交换增强安全性。

#### 密钥交换流程

```
1. 服务器生成 DH 密钥对 (S_private, S_public)
2. 服务器发送 S_public 给客户端
3. 客户端生成 DH 密钥对 (C_private, C_public)
4. 客户端计算共享密钥: K = (S_public ^ C_private) mod p
5. 客户端发送 C_public 给服务器
6. 服务器计算共享密钥: K = (C_public ^ S_private) mod p
7. 使用 K 派生 AES 密钥
8. 客户端加密用户凭据并发送
```

#### 实现

```cpp
void ClientConnection::AuthMsLogonII()
{
    // 接收服务器公钥（512位 = 64字节）
    unsigned char serverPubKey[64];
    ReadExact((char*)serverPubKey, 64);
    
    // 生成客户端密钥对
    unsigned char clientPubKey[64];
    unsigned char clientPrivKey[64];
    unsigned char sharedKey[64];
    
    // DH密钥交换
    DH dh;
    dh.GenerateKeys();
    dh.GetPublicKey(clientPubKey);
    dh.GetPrivateKey(clientPrivKey);
    
    // 计算共享密钥
    dh.ComputeSharedSecret(serverPubKey, sharedKey);
    
    // 发送客户端公钥
    WriteExact((char*)clientPubKey, 64);
    
    // 从共享密钥派生AES密钥
    unsigned char aesKey[32];
    DeriveKey(sharedKey, 64, aesKey, 32);
    
    // 获取用户凭据
    AuthDialog authDlg;
    authDlg.DoDialog(dtUserPass, m_host, m_port);
    
    // 准备凭据数据
    char credentials[256];
    memset(credentials, 0, sizeof(credentials));
    strncpy(credentials, authDlg.m_user, 64);
    strncpy(credentials + 64, authDlg.m_domain, 64);
    strncpy(credentials + 128, authDlg.m_passwd, 64);
    
    // 使用AES加密凭据
    AESCipher aes;
    aes.Init(256, aesKey);
    aes.Encrypt(credentials, 256);
    
    // 发送加密凭据
    WriteExact(credentials, 256);
    
    // 验证结果
    CARD32 authResult;
    ReadExact((char*)&authResult, sizeof(authResult));
    
    if (Swap32IfLE(authResult) != 0) {
        throw AuthenticationExc("MS-Logon II authentication failed");
    }
}
```

### 3.3 MS-Logon III（现代版本）

MS-Logon III 使用 X25519 和 AES-256-GCM，提供最强的安全性。

#### 特点
- **密钥交换**：X25519（Curve25519 ECDH）
- **加密算法**：AES-256-GCM（认证加密）
- **前向保密**：每次连接生成新的临时密钥对

#### 实现

```cpp
void ClientConnection::AuthMsLogonIII()
{
    // 接收服务器X25519公钥（32字节）
    unsigned char serverPubKey[32];
    ReadExact((char*)serverPubKey, 32);
    
    // 生成客户端X25519密钥对
    unsigned char clientPubKey[32];
    unsigned char clientPrivKey[32];
    unsigned char sharedKey[32];
    
    // 使用 libsodium 生成密钥对
    crypto_box_keypair(clientPubKey, clientPrivKey);
    
    // 计算共享密钥（X25519）
    crypto_scalarmult(sharedKey, clientPrivKey, serverPubKey);
    
    // 发送客户端公钥
    WriteExact((char*)clientPubKey, 32);
    
    // 使用 HKDF 从共享密钥派生 AES 密钥和 nonce
    unsigned char aesKey[32];
    unsigned char aesNonce[12];
    unsigned char info[] = "UltraVNC MS-Logon III";
    
    HKDF(aesKey, 32, sharedKey, 32, NULL, 0, info, sizeof(info));
    HKDF(aesNonce, 12, sharedKey, 32, NULL, 0, info, sizeof(info));
    
    // 获取用户凭据
    AuthDialog authDlg;
    authDlg.DoDialog(dtUserPassRSA, m_host, m_port);
    
    // 准备凭据
    struct Credentials {
        char username[64];
        char domain[64];
        char password[256];
    } creds;
    
    memset(&creds, 0, sizeof(creds));
    strncpy(creds.username, authDlg.m_user, 64);
    strncpy(creds.domain, authDlg.m_domain, 64);
    strncpy(creds.password, authDlg.m_passwd, 256);
    
    // AES-256-GCM 加密
    unsigned char ciphertext[sizeof(creds)];
    unsigned char tag[16];
    
    aes_gcm_encrypt(aesKey, aesNonce,
                    (unsigned char*)&creds, sizeof(creds),
                    NULL, 0,  // 无附加数据
                    ciphertext, tag);
    
    // 发送加密凭据和认证标签
    WriteExact((char*)ciphertext, sizeof(ciphertext));
    WriteExact((char*)tag, 16);
    
    // 验证结果
    CARD32 authResult;
    ReadExact((char*)&authResult, sizeof(authResult));
    
    if (Swap32IfLE(authResult) != 0) {
        throw AuthenticationExc("MS-Logon III authentication failed");
    }
}
```

### 4.2 TLS 实现

#### TLSSession 类

```cpp
struct TLSSession
{
    enum State {
        StateNew = 0,
        StateClosed = 1,
        StateHandshakeStart = 2,
        StatePostHandshake = 8,
        StateShutdown = 9,
    };
    
    State           state;
    wchar_t         *hostName;
    bool            isServer;
    PCCERT_CONTEXT  pLocalCert, pRemoteCert;
    DWORD           contextReq;
    CredHandle      hCredentials;
    CtxtHandle      hContext;
    SecBufferDesc   inDesc, outDesc;
    SecBuffer       inBuffers[5], outBuffers[5];
    SecPkgContext_StreamSizes tlsSizes;
    
    void Init(TCHAR *_hostName, bool _isServer = false, 
              PCERT_CONTEXT _pLocalCert = NULL)
    {
        hostName = _hostName;
        isServer = _isServer;
        pLocalCert = _pLocalCert;
        state = StateHandshakeStart;
        
        // 获取凭据句柄
        SCHANNEL_CRED schannelCred = {0};
        schannelCred.dwVersion = SCHANNEL_CRED_VERSION;
        schannelCred.grbitEnabledProtocols = SP_PROT_TLS1_2_CLIENTS;
        schannelCred.cCreds = _pLocalCert ? 1 : 0;
        schannelCred.paCred = _pLocalCert ? &_pLocalCert : NULL;
        
        AcquireCredentialsHandle(NULL, UNISP_NAME, 
                                 SECPKG_CRED_OUTBOUND,
                                 NULL, &schannelCred, 
                                 NULL, NULL, &hCredentials, NULL);
    }
    
    bool Handshake(DynBuffer &inbuf, DynBuffer &outbuf)
    {
        while (true) {
            inBuffers[0].BufferType = SECBUFFER_TOKEN;
            inBuffers[0].pvBuffer = inbuf.GetHead();
            inBuffers[0].cbBuffer = inbuf.GetAvailable();
            
            inBuffers[1].BufferType = SECBUFFER_EMPTY;
            inBuffers[2].BufferType = SECBUFFER_EMPTY;
            inBuffers[3].BufferType = SECBUFFER_EMPTY;
            
            outBuffers[0].BufferType = SECBUFFER_TOKEN;
            outBuffers[0].pvBuffer = outbuf.EnsureFree(0x10000);
            outBuffers[0].cbBuffer = 0x10000;
            
            SECURITY_STATUS ss = InitializeSecurityContext(
                &hCredentials, 
                state == StateHandshakeStart ? NULL : &hContext,
                hostName,
                ISC_REQ_SEQUENCE_DETECT | ISC_REQ_REPLAY_DETECT |
                ISC_REQ_CONFIDENTIALITY | ISC_REQ_ALLOCATE_MEMORY |
                ISC_REQ_STREAM,
                0, 0, &inDesc, 0, &hContext, &outDesc,
                NULL, NULL);
            
            if (ss == SEC_E_OK) {
                state = StatePostHandshake;
                QueryContextAttributes(&hContext, SECPKG_ATTR_STREAM_SIZES,
                                       &tlsSizes);
                return true;
            }
            
            if (ss == SEC_I_CONTINUE_NEEDED) {
                state = StateHandshakeStart + 1;
                outbuf.size += outBuffers[0].cbBuffer;
                return false;
            }
            
            throw Exception("TLS handshake failed: %d", ss);
        }
    }
};
```

#### TLS 认证入口

```cpp
void ClientConnection::AuthTLS()
{
    TLSSession tls;
    DynBuffer inbuf, outbuf;
    
    // 初始化TLS会话
    tls.Init(m_host);
    
    // 握手循环
    while (!tls.IsReady()) {
        if (!tls.Handshake(inbuf, outbuf)) {
            // 发送握手数据
            if (outbuf.GetAvailable() > 0) {
                WriteExact((char*)outbuf.GetHead(), outbuf.GetAvailable());
                outbuf.pos = outbuf.size = 0;
            }
            
            // 接收握手响应
            int available = WaitForReadable();
            if (available > 0) {
                ReadExact((char*)inbuf.EnsureFree(available), available);
                inbuf.size += available;
            }
        }
    }
    
    // 验证服务器证书（可选）
    if (!m_opts->m_AllowUntrustedServers) {
        VerifyServerCertificate(tls.pRemoteCert);
    }
    
    // TLS通道建立完成，后续所有通信都通过TLS加密
    m_fTlsEnabled = true;
    m_tlsSession = &tls;
}
```

### 4.3 VeNCrypt 扩展

VeNCrypt 是对 TLS 的扩展，支持多种子认证类型。

```cpp
void ClientConnection::AuthVeNCrypt()
{
    // 首先建立TLS通道
    AuthTLS();
    
    // VeNCrypt版本协商
    CARD8 majorVersion, minorVersion;
    ReadExact((char*)&majorVersion, 1);
    ReadExact((char*)&minorVersion, 1);
    
    if (majorVersion != 0 || minorVersion < 2) {
        throw ProtocolExc("Unsupported VeNCrypt version");
    }
    
    // 发送客户端版本
    WriteExact((char*)&majorVersion, 1);
    WriteExact((char*)&minorVersion, 1);
    
    // 接收子认证类型数量
    CARD8 nTypes;
    ReadExact((char*)&nTypes, 1);
    
    // 读取子认证类型列表
    CARD32 subTypes[32];
    ReadExact((char*)subTypes, nTypes * sizeof(CARD32));
    
    // 选择认证类型（优先级：X509None > X509Vnc > TLSNone > TLSVnc）
    CARD32 selectedType = 0;
    for (int i = 0; i < nTypes; i++) {
        CARD32 type = Swap32IfLE(subTypes[i]);
        if (type == rfbVeNCryptX509None) {
            selectedType = type;
            break;
        } else if (type == rfbVeNCryptX509Vnc || 
                   type == rfbVeNCryptTLSNone ||
                   type == rfbVeNCryptTLSVnc) {
            selectedType = type;
        }
    }
    
    // 发送选择的类型
    CARD32 selectedTypeLE = Swap32IfLE(selectedType);
    WriteExact((char*)&selectedTypeLE, sizeof(CARD32));
    
    // 根据子类型执行相应认证
    switch (selectedType) {
        case rfbVeNCryptX509None:
        case rfbVeNCryptTLSNone:
            // 仅TLS加密，无额外认证
            break;
            
        case rfbVeNCryptX509Vnc:
        case rfbVeNCryptTLSVnc:
            // TLS + VNC密码认证
            AuthVnc();
            break;
            
        default:
            throw ProtocolExc("No suitable VeNCrypt subtype");
    }
}
```

## 5. RSA-AES 高强度认证

### 5.1 RSA-AES 认证概述

RSA-AES 提供最强的安全性，结合了：
- **RSA-2048/3072/4096**：公钥加密密钥交换
- **AES-128/256**：对称加密数据传输
- **CMAC**：消息认证码确保完整性

### 5.2 AES 加密器实现

```cpp
struct AESCipher
{
    static const DWORD BlockSize = 16;
    
    HCRYPTPROV hProv;
    HCRYPTKEY hKey;
    
    bool Init(DWORD keySize, void *key)
    {
        // 获取CryptoAPI提供者
        if (!CryptAcquireContext(&hProv, NULL, NULL, 
                                 PROV_RSA_AES, CRYPT_VERIFYCONTEXT)) {
            return false;
        }
        
        // 准备密钥BLOB
        struct SymKeyBlob {
            BLOBHEADER hdr;
            DWORD cbKeySize;
            BYTE key[32];
        } keyBlob;
        
        keyBlob.hdr.bType = PLAINTEXTKEYBLOB;
        keyBlob.hdr.bVersion = CUR_BLOB_VERSION;
        keyBlob.hdr.aiKeyAlg = (keySize == 128 ? CALG_AES_128 : CALG_AES_256);
        keyBlob.cbKeySize = keySize / 8;
        memcpy(keyBlob.key, key, keyBlob.cbKeySize);
        
        // 导入密钥
        if (!CryptImportKey(hProv, (BYTE*)&keyBlob,
                           offsetof(SymKeyBlob, key) + keyBlob.cbKeySize,
                           NULL, 0, &hKey)) {
            return false;
        }
        
        // 设置ECB模式
        DWORD mode = CRYPT_MODE_ECB;
        CryptSetKeyParam(hKey, KP_MODE, (BYTE*)&mode, 0);
        
        return true;
    }
    
    bool Encrypt(void *buf, DWORD size = BlockSize)
    {
        return CryptEncrypt(hKey, NULL, FALSE, 0, (BYTE*)buf, &size, size);
    }
    
    bool Decrypt(void *buf, DWORD size = BlockSize)
    {
        return CryptDecrypt(hKey, NULL, FALSE, 0, (BYTE*)buf, &size);
    }
};
```

### 5.3 CMAC 消息认证

```cpp
struct CMACAuth
{
    static const DWORD BlockSize = 16;
    
    AESCipher *cipher;
    BYTE k1[BlockSize], k2[BlockSize];
    BYTE pad[BlockSize];
    DWORD pos;
    
    bool Init(AESCipher &c)
    {
        cipher = &c;
        Reset();
        
        // 计算子密钥k1和k2
        cipher->Encrypt(pad);
        DoubleBlock(pad, k1);    // k1 = L * 2
        DoubleBlock(k1, k2);    // k2 = k1 * 2
        
        Reset();
        return true;
    }
    
    void Reset()
    {
        memset(pad, 0, sizeof(pad));
        pos = 0;
    }
    
    bool Process(void *buf, DWORD size)
    {
        // 异或输入数据到缓冲区
        for (DWORD i = 0; i < size; i++) {
            if (pos == BlockSize) {
                cipher->Encrypt(pad);
                pos = 0;
            }
            pad[pos++] ^= ((BYTE*)buf)[i];
        }
        return true;
    }
    
    bool Finalize(void *tag, DWORD size = BlockSize)
    {
        // 最后一个块的特殊处理
        if (pos < BlockSize) {
            pad[pos] ^= 0x80;  // 添加补位标记
        }
        
        // 选择k1或k2
        BYTE *key = (pos < BlockSize ? k2 : k1);
        
        // 异或子密钥
        for (DWORD i = 0; i < BlockSize; i++) {
            pad[i] ^= key[i];
        }
        
        // 加密得到标签
        cipher->Encrypt(pad);
        
        // 返回认证标签（可截断）
        memcpy(tag, pad, min(size, BlockSize));
        pos = 0;
        
        return true;
    }
    
    static void DoubleBlock(BYTE *in, BYTE *out)
    {
        // GF(2^128)上的乘2运算
        DWORD c = 0;
        for (int i = BlockSize - 1; i >= 0; i--) {
            DWORD t = in[i];
            out[i] = (BYTE)((t << 1) | c);
            c = ((t & 0x80) != 0);
        }
        // 如果最高位为1，需要异或常数0x87
        out[BlockSize - 1] ^= c * 0x87;
    }
};
```

### 5.4 RSA-AES 认证流程

```cpp
void ClientConnection::AuthRSAAES(int keySize, bool encrypted)
{
    // keySize: 128或256位AES
    // encrypted: 是否加密整个会话
    
    // 1. 接收服务器RSA公钥（模数n和指数e）
    CARD16 keyLen = 0;
    ReadExact((char*)&keyLen, 2);
    keyLen = Swap16IfLE(keyLen);
    
    unsigned char modulus[512];  // 最多4096位
    ReadExact((char*)modulus, keyLen);
    
    CARD16 expLen = 0;
    ReadExact((char*)&expLen, 2);
    expLen = Swap16IfLE(expLen);
    
    unsigned char exponent[8];
    ReadExact((char*)exponent, expLen);
    
    // 2. 生成随机AES密钥
    unsigned char aesKey[32];
    CryptGenRandom(m_hCryptProv, keySize / 8, aesKey);
    
    // 3. 使用服务器公钥加密AES密钥
    // RSA加密格式：PKCS#1 v2.1 OAEP
    unsigned char encryptedKey[512];
    int encryptedLen = RSAEncrypt(modulus, keyLen * 8, exponent, expLen,
                                  aesKey, keySize / 8, encryptedKey);
    
    // 发送加密的AES密钥
    WriteExact((char*)encryptedKey, encryptedLen);
    
    // 4. 接收服务器验证数据
    unsigned char serverRandom[32];
    ReadExact((char*)serverRandom, 32);
    
    // 5. 计算共享密钥和初始化向量
    unsigned char sharedKey[32];
    HKDF(sharedKey, 32, aesKey, keySize / 8, serverRandom, 32, 
         "UltraVNC RSA-AES", 16);
    
    unsigned char iv[16];
    HKDF(iv, 16, aesKey, keySize / 8, serverRandom, 32, 
         "UltraVNC IV", 11);
    
    // 6. 初始化AES加密器
    AESCipher aes;
    aes.Init(keySize, sharedKey);
    
    CMACAuth cmac;
    cmac.Init(aes);
    
    // 7. 如果需要用户认证
    if (encrypted) {
        // 获取用户凭据
        AuthDialog authDlg;
        authDlg.DoDialog(dtUserPassRSA, m_host, m_port);
        
        // 加密用户凭据
        char credentials[256];
        memset(credentials, 0, sizeof(credentials));
        strncpy(credentials, authDlg.m_user, 64);
        strncpy(credentials + 64, authDlg.m_passwd, 192);
        
        // AES加密凭据
        for (int i = 0; i < sizeof(credentials); i += 16) {
            aes.Encrypt(credentials + i, 16);
        }
        
        // 计算CMAC
        cmac.Process(credentials, sizeof(credentials));
        unsigned char tag[16];
        cmac.Finalize(tag, 16);
        
        // 发送加密凭据和认证标签
        WriteExact(credentials, sizeof(credentials));
        WriteExact((char*)tag, 16);
    }
    
    // 8. 验证服务器响应
    unsigned char serverTag[16];
    ReadExact((char*)serverTag, 16);
    
    // 验证服务器认证标签
    if (!VerifyServerTag(serverTag, sharedKey)) {
        throw AuthenticationExc("Server authentication failed");
    }
    
    // 9. 启用会话加密
    if (encrypted) {
        m_fRSAAESEncrypted = true;
        m_aesSession = new AESCipher();
        m_aesSession->Init(keySize, sharedKey);
    }
    
    vnclog.Print(0, _T("RSA-AES authentication successful\n"));
}
```

### 6.2 DSM 插件加载和使用

```cpp
void ClientConnection::LoadDSMPlugin(bool fForceReload)
{
    if (!m_opts->m_fUseDSMPlugin) {
        return;
    }
    
    if (m_pDSMPlugin != NULL && !fForceReload) {
        return;  // 已加载
    }
    
    // 卸载旧插件
    if (m_pDSMPlugin != NULL) {
        UnloadDSMPlugin();
    }
    
    // 加载插件DLL
    HMODULE hPlugin = LoadLibrary(m_opts->m_szDSMPluginFilename);
    if (hPlugin == NULL) {
        throw WarningException("Failed to load DSM plugin");
    }
    
    // 获取插件创建函数
    typedef IPlugin* (*CreatePluginFunc)();
    CreatePluginFunc CreatePlugin = 
        (CreatePluginFunc)GetProcAddress(hPlugin, "CreatePlugin");
    
    if (CreatePlugin == NULL) {
        FreeLibrary(hPlugin);
        throw WarningException("Invalid DSM plugin format");
    }
    
    // 创建插件实例
    m_pPluginInterface = CreatePlugin();
    if (m_pPluginInterface == NULL) {
        FreeLibrary(hPlugin);
        throw WarningException("Failed to create DSM plugin instance");
    }
    
    // 初始化插件
    if (!m_pPluginInterface->Initialize()) {
        delete m_pPluginInterface;
        FreeLibrary(hPlugin);
        throw WarningException("DSM plugin initialization failed");
    }
    
    m_hPluginModule = hPlugin;
    m_fUsePlugin = true;
    
    vnclog.Print(0, _T("DSM plugin loaded: %s\n"), 
                 m_pPluginInterface->GetName());
}

{
```

```cpp
    ReadRaw(buf, bytes);
    
    if (m_fUsePlugin && m_pPluginInterface) {
        // 第一步解密
        BYTE* restored = RestoreBufferStep1((BYTE*)buf, bytes, &newLen);
        
        // 第二步解密
        restored = RestoreBufferStep2(restored, newLen, &finalLen);
        
        // 复制解密后的数据
        memcpy(buf, restored, finalLen);
    }
}
```

## 8. 安全级别对比

### 8.1 详细对比表

| 特性 | VNC Auth | MS-Logon I | MS-Logon II | MS-Logon III | TLS | RSA-AES |
|-----|----------|-----------|-------------|--------------|-----|---------|
| 加密算法 | DES | DES | AES-128 | AES-256 | TLS 1.2/1.3 | AES-128/256 |
| 密钥长度 | 56位 | 56位 | 128位 | 256位 | 可变 | 128/256位 |
| 密钥交换 | 无 | 无 | DH | X25519 | RSA/ECDHE | RSA-2048+ |
| 前向保密 | 否 | 否 | 是 | 是 | 是 | 是 |
| 身份验证 | 密码 | Windows用户 | Windows用户 | Windows用户 | 证书+密码 | 密码 |
| 防重放 | 部分 | 部分 | 是 | 是 | 是 | 是 |
| 完整性验证 | 否 | 否 | 否 | CMAC | HMAC | CMAC |
| 性能开销 | 低 | 低 | 中 | 中-高 | 中-高 | 中 |

### 8.2 安全性评估

#### VNC Auth (传统)
- ✅ 实现简单，兼容性好
- ❌ DES算法已不安全（56位密钥）
- ❌ 无前向保密
- ❌ 易受暴力破解

**推荐场景**：仅限可信内网环境

#### MS-Logon I
- ✅ 集成Windows用户认证
- ❌ 仍使用不安全的DES
- ❌ 凭据明文传输（加密前）

**推荐场景**：旧系统兼容

#### MS-Logon II
- ✅ 使用AES-128加密
- ✅ DH密钥交换
- ✅ 前向保密
- ⚠️ 无完整性验证

**推荐场景**：一般企业环境

#### MS-Logon III
- ✅ AES-256-GCM认证加密
- ✅ X25519现代密钥交换
- ✅ 完整性验证
- ✅ 前向保密

**推荐场景**：高安全需求环境

#### TLS/VeNCrypt
- ✅ 工业标准加密
- ✅ 证书验证
- ✅ 灵活的密码套件
- ⚠️ 需要证书管理

**推荐场景**：企业级部署

#### RSA-AES
- ✅ 最强安全性
- ✅ 多层加密验证
- ✅ 完整性保证
- ❌ 性能开销较大

**推荐场景**：高度敏感数据

## 10. 学习要点总结

### 10.1 核心概念
1. **认证 vs 加密**：认证验证身份，加密保护数据
2. **密钥交换**：安全协商会话密钥
3. **前向保密**：密钥泄露不影响历史通信
4. **完整性验证**：确保数据未被篡改

### 10.2 实现要点
1. **密码学原语**：正确使用DES、AES、RSA等算法
2. **随机数生成**：使用密码学安全的随机数
3. **密钥派生**：使用标准KDF（如HKDF）
4. **错误处理**：避免通过错误信息泄露敏感数据

### 10.3 安全编码实践
1. **安全清零**：使用后清除内存中的密钥
2. **常量时间比较**：防止时序攻击
3. **输入验证**：严格验证所有输入数据
4. **最小权限**：仅请求必要的权限

### 10.4 调试技巧
1. **日志记录**：记录认证过程（不含密钥）
2. **抓包分析**：使用Wireshark分析TLS握手
3. **错误追踪**：区分客户端和服务器错误
4. **性能测试**：评估加密性能影响
