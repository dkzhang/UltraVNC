# UltraVNC Viewer 编码解码系统详解

## 1. 编码系统概述

UltraVNC Viewer 支持多种 VNC 编码方式，以适应不同的网络条件和显示内容类型。编码系统采用策略模式设计，根据图像特征和网络带宽动态选择最优编码方式。

### 1.1 支持的编码类型

| 编码类型 | 定义常量 | 源文件 | 特点 |
|---------|---------|--------|------|
| Raw | rfbEncodingRaw | ClientConnectionRaw.cpp | 原始像素数据，无压缩 |
| RRE | rfbEncodingRRE | ClientConnectionRRE.cpp | 上升矩形编码，适合大面积单色区域 |
| CoRRE | rfbEncodingCoRRE | ClientConnectionCoRRE.cpp | 紧凑RRE，优化小矩形编码 |
| Hextile | rfbEncodingHextile | ClientConnectionHextile.cpp | 瓦片编码，分块处理 |
| Zlib | rfbEncodingZlib | ClientConnectionZlib.cpp | Zlib压缩编码 |
| ZlibHex | rfbEncodingZlibHex | ClientConnectionZlibHex.cpp | Zlib+Hextile混合编码 |
| Tight | rfbEncodingTight | ClientConnectionTight.cpp | TightVNC编码，多种压缩方式 |
| Ultra | rfbEncodingUltra | ClientConnectionUltra.cpp | UltraVNC专用编码（LZO压缩） |
| Ultra2 | rfbEncodingUltra2 | ClientConnectionUltra2.cpp | UltraVNC第二代编码 |
| ZRLE | rfbEncodingZRLE | zrle.cpp | 实时编码，适合连续变化 |
| XZ | rfbEncodingXZ | xz.cpp | XZ压缩编码 |

### 1.2 编码选择策略

```cpp
// VNCOptions中的编码优先级设置
std::vector<int> m_PreferredEncodings;

// 自动检测模式下的编码选择
void ClientConnection::HandleQuickOption()
{
    switch (m_opts->m_quickoption) {
        case 1:  // 局域网高速连接
            m_opts->m_PreferredEncodings = {
                rfbEncodingUltra2,
                rfbEncodingUltra,
                rfbEncodingZRLE,
                rfbEncodingTight
            };
            break;
        case 2:  // 中速连接
            m_opts->m_PreferredEncodings = {
                rfbEncodingTight,
                rfbEncodingZRLE,
                rfbEncodingUltra
            };
            break;
        case 3:  // 低速连接
            m_opts->m_PreferredEncodings = {
                rfbEncodingTight,
                rfbEncodingZlibHex,
                rfbEncodingHextile
            };
            break;
    }
}
```

## 2. 基础编码方式

### 2.1 Raw 编码（原始编码）

Raw 编码是最简单的编码方式，直接传输原始像素数据。

#### 编码格式
```
+----------------+----------------+-------------+
| 宽度 (16 bits) | 高度 (16 bits) | 像素数据... |
+----------------+----------------+-------------+
```

#### 解码实现
```cpp
void ClientConnection::ReadRawRect(rfbFramebufferUpdateRectHeader *pfburh)
{
    UINT numpixels = pfburh->r.w * pfburh->r.h;
    UINT bytesPerPixel = m_myFormat.bitsPerPixel / 8;
    UINT numRawBytes = numpixels * bytesPerPixel;
    
    // 读取原始像素数据
    CheckBufferSize(numRawBytes);
    ReadExact(m_netbuf, numRawBytes);
    
    // 直接写入帧缓冲
    omni_mutex_lock l(m_bitmapdcMutex);
    if (m_DIBbits) {
        ConvertAll(pfburh->r.w, pfburh->r.h, 
                   pfburh->r.x, pfburh->r.y,
                   bytesPerPixel,
                   (BYTE*)m_netbuf, 
                   (BYTE*)m_DIBbits,
                   m_si.framebufferWidth,
                   m_si.framebufferHeight);
    }
}
```

#### 特点分析
- **优点**：实现简单，无需解码计算
- **缺点**：数据量大，网络传输效率低
- **适用场景**：局域网高速环境、测试调试

---

### 2.2 RRE 编码（Rise-and-Run-length Encoding）

RRE 编码将图像分解为一个大背景矩形和多个前景子矩形。

#### 编码格式
```
+-------------+-------------+------------------+----------------+
| 背景色 (N)  | 子矩形数量  | 子矩形 1 数据... | 子矩形 n 数据  |
+-------------+-------------+------------------+----------------+

每个子矩形数据：
+-------------+------------+------------+----------+
| 颜色 (N)    | X (16 bit) | Y (16 bit) | W,H      |
+-------------+------------+------------+----------+
```

#### 解码实现
```cpp
void ClientConnection::ReadRRERect(rfbFramebufferUpdateRectHeader *pfburh)
{
    // 读取RRE头部（背景色和子矩形数量）
    char tmpbuf[sz_rfbRREHeader + 4];  // 最大像素4字节
    rfbRREHeader *prreh = (rfbRREHeader *)tmpbuf;
    CARD8 *pcolor = (CARD8 *)tmpbuf + sz_rfbRREHeader;
    
    ReadExact(tmpbuf, sz_rfbRREHeader + m_minPixelBytes);
    prreh->nSubrects = Swap32IfLE(prreh->nSubrects);
    
    omni_mutex_lock l(m_bitmapdcMutex);
    
    // 绘制背景矩形
    FillSolidRect_ultra(pfburh->r.x, pfburh->r.y, 
                        pfburh->r.w, pfburh->r.h, 
                        m_myFormat.bitsPerPixel, pcolor);
    
    if (prreh->nSubrects == 0) return;
    
    // 读取并绘制所有子矩形
    int subRectSize = m_minPixelBytes + sz_rfbRectangle;
    CheckBufferSize(subRectSize * prreh->nSubrects);
    ReadExact(m_netbuf, subRectSize * prreh->nSubrects);
    
    BYTE *p = (BYTE *)m_netbuf;
    for (CARD32 i = 0; i < prreh->nSubrects; i++) {
        rfbRectangle *pRect = (rfbRectangle *)(p + m_minPixelBytes);
        
        // 绘制子矩形
        FillSolidRect_ultra(
            Swap16IfLE(pRect->x) + pfburh->r.x,
            Swap16IfLE(pRect->y) + pfburh->r.y,
            Swap16IfLE(pRect->w),
            Swap16IfLE(pRect->h),
            m_myFormat.bitsPerPixel, p);
        p += subRectSize;
    }
}
```

#### 特点分析
- **压缩原理**：利用图像中的单色区域特征
- **适用场景**：窗口界面、按钮、图标等大面积单色区域
- **压缩效率**：取决于单色区域比例，通常可达50%-90%

---

### 2.3 CoRRE 编码（Compact RRE）

CoRRE 是 RRE 的改进版本，针对小矩形进行了优化。

#### 改进点
- 子矩形坐标和尺寸使用 8 位值，节省空间
- 子矩形尺寸限制在 255x255 以内
- 适合小图像块的编码

---

### 2.4 Hextile 编码（瓦片编码）

Hextile 将图像分割为 16x16 的瓦片，每个瓦片独立编码。

#### 编码结构
```
+----------+----------+----------+-----+
| 瓦片 1   | 瓦片 2   | 瓦片 3   | ... |
+----------+----------+----------+-----+
每个瓦片：16x16像素（边缘可能小于16）
```

#### 子编码类型
```cpp
#define rfbHextileRaw                  (1 << 0)  // 原始像素
#define rfbHextileBackgroundSpecified  (1 << 1)  // 指定背景色
#define rfbHextileForegroundSpecified  (1 << 2)  // 指定前景色
#define rfbHextileAnySubrects          (1 << 3)  // 包含子矩形
#define rfbHextileSubrectsColoured     (1 << 4)  // 子矩形有独立颜色
```

#### 解码实现（模板函数）
```cpp
#define DEFINE_HEXTILE(bpp)                                           \
void ClientConnection::HandleHextileEncoding##bpp(                   \
    int rx, int ry, int rw, int rh)                                   \
{                                                                     \
    CARD##bpp bg, fg;                                                 \
    CARD8 subencoding, nSubrects;                                     \
                                                                      \
    for (int y = ry; y < ry+rh; y += 16) {                           \
        for (int x = rx; x < rx+rw; x += 16) {                        \
            int w = min(16, rx+rw - x);                               \
            int h = min(16, ry+rh - y);                               \
                                                                      \
            ReadExact((char *)&subencoding, 1);                       \
                                                                      \
            if (subencoding & rfbHextileRaw) {                        \
                /* Raw编码：直接读取像素数据 */                        \
                ReadExact(m_netbuf, w * h * (bpp / 8));              \
                SETPIXELS(m_netbuf, bpp, x, y, w, h);                 \
                continue;                                             \
            }                                                         \
                                                                      \
            /* 读取或使用缓存的背景色 */                              \
            if (subencoding & rfbHextileBackgroundSpecified) {       \
                ReadExact((char *)&bg, (bpp/8));                      \
            }                                                         \
            FillSolidRect_ultra(x, y, w, h, bpp, (BYTE*)&bg);         \
                                                                      \
            /* 读取或使用缓存的前景色 */                              \
            if (subencoding & rfbHextileForegroundSpecified) {       \
                ReadExact((char *)&fg, (bpp/8));                      \
            }                                                         \
                                                                      \
            if (!(subencoding & rfbHextileAnySubrects)) continue;    \
                                                                      \
            ReadExact((char *)&nSubrects, 1);                         \
                                                                      \
            if (subencoding & rfbHextileSubrectsColoured) {          \
                /* 彩色子矩形：每个矩形有自己的颜色 */                \
                ReadExact(m_netbuf, nSubrects * (2 + (bpp/8)));       \
                for (int i = 0; i < nSubrects; i++) {                \
                    memcpy(&fg, ptr, bpp/8);                          \
                    ptr += (bpp/8);                                   \
                    /* 解码子矩形坐标和尺寸 */                        \
                    sx = *ptr >> 4;                                   \
                    sy = *ptr++ & 0x0f;                               \
                    sw = (*ptr >> 4) + 1;                             \
                    sh = (*ptr++ & 0x0f) + 1;                         \
                    FillSolidRect_ultra(x+sx, y+sy, sw, sh, bpp,       \
                                       (BYTE*)&fg);                   \
                }                                                     \
            } else {                                                  \
                /* 单色子矩形：都使用前景色 */                        \
                ReadExact(m_netbuf, nSubrects * 2);                  \
                for (int i = 0; i < nSubrects; i++) {                \
                    sx = *ptr >> 4;                                   \
                    sy = *ptr++ & 0x0f;                               \
                    sw = (*ptr >> 4) + 1;                             \
                    sh = (*ptr++ & 0x0f) + 1;                         \
                    FillSolidRect_ultra(x+sx, y+sy, sw, sh, bpp,       \
                                       (BYTE*)&fg);                   \
                }                                                     \
            }                                                         \
        }                                                             \
    }                                                                 \
}

// 实例化不同色深的处理函数
DEFINE_HEXTILE(8)
DEFINE_HEXTILE(16)
DEFINE_HEXTILE(32)
```

#### 特点分析
- **优点**：
  - 分块处理，提高局部性
  - 支持多种子编码，灵活适应不同内容
  - 可缓存背景色和前景色，减少重复传输
- **缺点**：
  - 16x16固定瓦片大小可能不够灵活
  - 对复杂图像压缩效果有限
- **适用场景**：中等复杂度的桌面界面

## 3. 压缩编码方式

### 3.1 Zlib 编码

Zlib 编码使用 DEFLATE 算法压缩像素数据。

#### 编码格式
```
+-------------+----------------+
| 压缩字节数  | 压缩数据...     |
+-------------+----------------+
```

#### 解码实现
```cpp
void ClientConnection::ReadZlibRect(rfbFramebufferUpdateRectHeader *pfburh, 
                                     bool zstd)
{
    UINT numpixels = pfburh->r.w * pfburh->r.h;
    UINT numRawBytes = numpixels * m_minPixelBytes;
    
    rfbZlibHeader hdr;
    ReadExact((char *)&hdr, sz_rfbZlibHeader);
    UINT numCompBytes = Swap32IfLE(hdr.nBytes);
    
    // 读取压缩数据
    CheckBufferSize(numCompBytes);
    ReadExact(m_netbuf, numCompBytes);
    
    // 解压缩
    CheckZlibBufferSize(numRawBytes + 500);
    
    UltraVncZ *uz = zstd ? ultraVncZlib : ultraVncZEncoded;
    if (!zlibDecompress((unsigned char*)m_netbuf, 
                        (unsigned char*)m_zlibbuf, 
                        numCompBytes, numRawBytes, uz, zstd)) {
        return;
    }
    
    // 写入帧缓冲
    omni_mutex_lock l(m_bitmapdcMutex);
    if (m_DIBbits) {
        ConvertAll(pfburh->r.w, pfburh->r.h,
                   pfburh->r.x, pfburh->r.y,
                   m_myFormat.bitsPerPixel/8,
                   (BYTE*)m_zlibbuf, (BYTE*)m_DIBbits,
                   m_si.framebufferWidth, m_si.framebufferHeight);
    }
}
```

#### 特点分析
- **压缩率**：通常可达 40%-60%
- **计算开销**：中等，需要解压缩计算
- **适用场景**：中低带宽网络环境

---

### 3.2 ZlibHex 编码

ZlibHex 结合了 Hextile 的分块策略和 Zlib 压缩。

#### 编码策略
- 将图像分成 16x16 瓦片
- 每个瓦片可选择 Raw 或 Zlib 压缩
- 支持背景色、前景色和子矩形

#### 子编码类型
```cpp
enum {
    ZLIBHEX_RAW = 0,         // 原始数据
    ZLIBHEX_COMPRESS = 1,    // Zlib压缩
    ZLIBHEX_HEXTILE = 2      // Hextile子编码
};
```

#### 特点分析
- **优点**：兼顾压缩率和编码效率
- **缺点**：实现较复杂
- **适用场景**：低速网络环境

---

### 3.3 Tight 编码

Tight 是 TightVNC 项目开发的高效编码方式，支持多种压缩策略。

#### 编码控制字节
```cpp
#define rfbTightExplicitFilter   0x04  // 显式过滤器
#define rfbTightFill             0x08  // 纯色填充
#define rfbTightJpeg             0x09  // JPEG压缩
#define rfbTightMaxSubencoding  0x09   // 最大子编码值
```

#### 支持的压缩方式
1. **纯色填充**：仅传输颜色值，无需像素数据
2. **JPEG 压缩**：适合照片和复杂图像
3. **Zlib 压缩**：适合文本和线条图
4. **过滤器**：优化特定类型数据

#### 解码实现
```cpp
void ClientConnection::ReadTightRect(rfbFramebufferUpdateRectHeader *pfburh,
                                      bool zstd)
{
    CARD8 comp_ctl;
    ReadExact((char *)&comp_ctl, 1);
    
    /* 处理压缩流刷新 */
    for (int i = 0; i < 4; i++) {
        if (comp_ctl & 1) {
            UltraVncZ *uz = &ultraVncZTight[i];
            uz->endInflateStream(zstd);
        }
        comp_ctl >>= 1;
    }
    
    /* 纯色填充 */
    if (comp_ctl == rfbTightFill) {
        BYTE colorpointer[4];
        if (m_myFormat.depth == 24 && m_myFormat.redMax == 0xFF) {
            CARD8 fillColourBuf[3];
            ReadExact((char *)&fillColourBuf, 3);
            CARD32 *p = (CARD32*)colorpointer;
            *p = ((CARD32)fillColourBuf[0] << m_myFormat.redShift)
               | ((CARD32)fillColourBuf[1] << m_myFormat.greenShift)
               | ((CARD32)fillColourBuf[2] << m_myFormat.blueShift);
        } else {
            CARD32 fillColourBuf;
            ReadExact((char *)&fillColourBuf, m_myFormat.bitsPerPixel / 8);
            memcpy(colorpointer, &fillColourBuf, m_myFormat.bitsPerPixel / 8);
        }
        
        omni_mutex_lock l(m_bitmapdcMutex);
        FillSolidRect_ultra(pfburh->r.x, pfburh->r.y, 
                            pfburh->r.w, pfburh->r.h,
                            m_myFormat.bitsPerPixel, colorpointer);
        return;
    }
    
    /* JPEG 压缩 */
    if (comp_ctl == rfbTightJpeg) {
        DecompressJpegRect(pfburh->r.x, pfburh->r.y,
                           pfburh->r.w, pfburh->r.h);
        return;
    }
    
    /* 过滤器 + Zlib 压缩 */
    int bitsPixel;
    if ((comp_ctl & rfbTightExplicitFilter) != 0) {
        CARD8 filter_id;
        ReadExact((char *)&filter_id, 1);
        
        switch (filter_id) {
        case rfbTightFilterCopy:
            bitsPixel = InitFilterCopy(pfburh->r.w, pfburh->r.h);
            break;
        case rfbTightFilterPalette:
            bitsPixel = InitFilterPalette(pfburh->r.w, pfburh->r.h);
            break;
        case rfbTightFilterGradient:
            bitsPixel = InitFilterGradient(pfburh->r.w, pfburh->r.h);
            break;
        }
    } else {
        bitsPixel = InitFilterCopy(pfburh->r.w, pfburh->r.h);
    }
    
    // 小数据直接读取，大数据使用Zlib解压
    int rowSize = (pfburh->r.w * bitsPixel + 7) / 8;
    if (pfburh->r.h * rowSize < TIGHT_MIN_TO_COMPRESS) {
        CheckBufferSize(pfburh->r.h * rowSize);
        ReadExact(m_netbuf, pfburh->r.h * rowSize);
        CheckZlibBufferSize(pfburh->r.w * pfburh->r.h * 4);
        (this->*m_tightCurrentFilter)(pfburh->r.h);
        
        omni_mutex_lock l(m_bitmapdcMutex);
        SETPIXELS_NOCONV(m_zlibbuf, pfburh->r.x, pfburh->r.y,
                         pfburh->r.w, pfburh->r.h);
        return;
    }
    
    // Zlib 解压缩处理
    int compressedLen = ReadCompactLen();
    int stream_id = comp_ctl & 0x03;
    UltraVncZ *uz = &ultraVncZTight[stream_id];
    
    // ... 详细的解压和渲染流程
}
```

#### JPEG 解压实现
```cpp
void ClientConnection::DecompressJpegRect(int x, int y, int w, int h)
{
    int compressedLen = ReadCompactLen();
    CheckBufferSize(compressedLen);
    ReadExact(m_netbuf, compressedLen);
    
    // 使用 libjpeg-turbo 解压
    jpeg_source_mgr jsrc;
    jsrc.next_input_byte = (JOCTET*)m_netbuf;
    jsrc.bytes_in_buffer = compressedLen;
    
    struct jpeg_decompress_struct cinfo;
    struct jpeg_error_mgr jerr;
    
    cinfo.err = jpeg_std_error(&jerr);
    jpeg_create_decompress(&cinfo);
    cinfo.src = &jsrc;
    
    jpeg_read_header(&cinfo, TRUE);
    cinfo.out_color_space = JCS_RGB;
    
    jpeg_start_decompress(&cinfo);
    
    JSAMPROW row_pointer[1];
    while (cinfo.output_scanline < cinfo.output_height) {
        row_pointer[0] = (JSAMPROW)m_zlibbuf;
        jpeg_read_scanlines(&cinfo, row_pointer, 1);
        
        // 写入帧缓冲
        omni_mutex_lock l(m_bitmapdcMutex);
        // ... 像素转换和写入
    }
    
    jpeg_finish_decompress(&cinfo);
    jpeg_destroy_decompress(&cinfo);
}
```

void ClientConnection::FilterPalette(int numRows)
{
    // 将调色板索引转换为RGB值
    for (int y = 0; y < numRows; y++) {
        for (int x = 0; x < m_tightRectWidth; x++) {
            int idx = m_netbuf[y * m_tightRectWidth + x];
            memcpy(&m_zlibbuf[(y * m_tightRectWidth + x) * 4],
                   &m_tightPalette[idx], 4);
        }
    }
}

**Gradient 过滤器**：优化连续渐变色彩
```cpp
void ClientConnection::FilterGradient32(int numRows)
{
    CARD32 *src = (CARD32*)m_netbuf;
    CARD32 *dst = (CARD32*)m_zlibbuf;
    
    for (int y = 0; y < numRows; y++) {
        // 上一行数据用于预测
        CARD32 *prevRow = (CARD32*)&m_tightPrevRow;
        CARD32 prevPixel = 0;
        
        for (int x = 0; x < m_tightRectWidth; x++) {
            CARD32 predicted = 
                prevRow[x] + prevPixel - *prevRow;
            
            CARD32 diff = *src++;
            *dst++ = predicted + diff;
            
            prevRow[x] = prevPixel = dst[-1];
        }
    }
}
```

#### 特点分析
- **优点**：
  - 高压缩率（JPEG适合照片）
  - 多种过滤器优化不同类型数据
  - 自适应流式压缩
- **缺点**：实现复杂，计算开销大
- **适用场景**：广域网低速环境、复杂图像内容

## 4. UltraVNC 专用编码

### 4.1 Ultra 编码（LZO压缩）

Ultra 编码使用 LZO 算法实现高速压缩和解压。

#### 特点
- **压缩速度**：极快（实时压缩）
- **压缩率**：中等（30%-50%）
- **适用场景**：局域网高速环境

#### 解码实现
```cpp
void ClientConnection::ReadUltraRect(rfbFramebufferUpdateRectHeader *pfburh)
{
    UINT numpixels = pfburh->r.w * pfburh->r.h;
    UINT numRawBytes = numpixels * m_minPixelBytes;
    
    rfbZlibHeader hdr;
    ReadExact((char *)&hdr, sz_rfbZlibHeader);
    UINT numCompBytes = Swap32IfLE(hdr.nBytes);
    
    // 读取压缩数据
    CheckBufferSize(numCompBytes);
    ReadExact(m_netbuf, numCompBytes);
    
    // LZO 解压
    CheckZlibBufferSize(numRawBytes + 500);
    lzo_uint new_len = numRawBytes + 500;
    
    if (lzo1x_decompress_safe((BYTE*)m_netbuf, numCompBytes,
                               (BYTE*)m_zlibbuf, &new_len, NULL) != LZO_E_OK) {
        return;
    }
    
    // 写入帧缓冲
    omni_mutex_lock l(m_bitmapdcMutex);
    SoftCursorLockArea(pfburh->r.x, pfburh->r.y,
                       pfburh->r.w, pfburh->r.h);
    
    if (!Check_Rectangle_borders(pfburh->r.x, pfburh->r.y,
                                  pfburh->r.w, pfburh->r.h)) {
        return;
    }
    
    if (m_DIBbits) {
        ConvertAll_secure(pfburh->r.w, pfburh->r.h,
                          pfburh->r.x, pfburh->r.y,
                          m_myFormat.bitsPerPixel/8,
                          (BYTE*)m_zlibbuf, (BYTE*)m_DIBbits,
                          m_si.framebufferWidth, new_len,
                          m_si.framebufferHeight);
    }
}
```

#### LZO 算法优势
- **解压速度**：极快，适合实时应用
- **内存占用**：低，仅需少量工作内存
- **压缩效率**：平衡压缩率和速度

### 4.3 UltraZip 批量编码

UltraZip 将多个矩形打包压缩，减少网络往返。

#### 解码实现
```cpp
void ClientConnection::ReadUltraZip(rfbFramebufferUpdateRectHeader *pfburh,
                                     HRGN *prgn)
{
    // 头部编码：矩形数量和总字节数
    UINT nNbCacheRects = pfburh->r.x;
    UINT numRawBytes = pfburh->r.y + pfburh->r.w * 65535;
    
    // 安全检查
    if (numRawBytes > 106000000 || nNbCacheRects > 25000) {
        return;
    }
    
    rfbZlibHeader hdr;
    ReadExact((char *)&hdr, sz_rfbZlibHeader);
    UINT numCompBytes = Swap32IfLE(hdr.nBytes);
    
    if (numCompBytes > numRawBytes) return;
    
    CheckBufferSize(numCompBytes);
    ReadExact((char *)m_netbuf, numCompBytes);
    
    // LZO 解压
    CheckZlibBufferSize(numRawBytes + 500);
    lzo_uint new_len = numRawBytes + 500;
    
    if (lzo1x_decompress_safe((BYTE*)m_netbuf, numCompBytes,
                               (BYTE*)m_zlibbuf, &new_len, NULL) != LZO_E_OK) {
        return;
    }
    
    // 解析并渲染所有矩形
    BYTE* pzipbuf = m_zlibbuf;
    UINT m_zlibbuf_size = 0;
    
    for (UINT i = 0; i < nNbCacheRects; i++) {
        rfbFramebufferUpdateRectHeader surh;
        memcpy((char *)&surh, pzipbuf, sz_rfbFramebufferUpdateRectHeader);
        
        // 字节序转换
        surh.r.x = Swap16IfLE(surh.r.x);
        surh.r.y = Swap16IfLE(surh.r.y);
        surh.r.w = Swap16IfLE(surh.r.w);
        surh.r.h = Swap16IfLE(surh.r.h);
        surh.encoding = Swap32IfLE(surh.encoding);
        
        pzipbuf += sz_rfbFramebufferUpdateRectHeader;
        
        // 边界检查
        if (!Check_Rectangle_borders(surh.r.x, surh.r.y,
                                      surh.r.w, surh.r.h)) {
            return;
        }
        
        SoftCursorLockArea(surh.r.x, surh.r.y, 
                           surh.r.w, surh.r.h);
        
        if (surh.encoding == rfbEncodingRaw) {
            // 渲染Raw矩形
            if (m_DIBbits) {
                ConvertAll(surh.r.w, surh.r.h,
                          surh.r.x, surh.r.y,
                          m_myFormat.bitsPerPixel/8,
                          (BYTE*)pzipbuf, (BYTE*)m_DIBbits,
                          m_si.framebufferWidth, m_si.framebufferHeight);
            }
            pzipbuf += surh.r.w * surh.r.h * m_myFormat.bitsPerPixel/8;
            
            // 刷新显示
            RECT rect;
            rect.left = surh.r.x;
            rect.right = surh.r.x + surh.r.w;
            rect.top = surh.r.y;
            rect.bottom = surh.r.y + surh.r.h;
            
            if (!m_opts->m_Directx) {
                InvalidateRegion(&rect, prgn);
            }
        }
    }
}
```

#### 性能优势
- **批量处理**：减少网络往返次数
- **整体压缩**：利用矩形间的相关性
- **内存局部性**：提高缓存命中率

## 5. ZRLE 和 XZ 编码

### 5.1 ZRLE 编码（Zlib Run-Length Encoding）

ZRLE 结合了游程编码和 Zlib 压缩。

#### 编码结构
- 将图像分割为 64x64 的瓦片
- 每个瓦片使用游程编码（RLE）
- RLE 数据再用 Zlib 压缩

#### 解码实现
```cpp
void ClientConnection::zrleDecode(int x, int y, int w, int h, bool use_zstd)
{
    CheckBufferSize(rfbZRLETileWidth * rfbZRLETileHeight * 4);
    
    // ZYWRLE 质量级别设置
    if (zywrle) {
        if (!m_opts->m_enableJpegCompression) {
            zywrle_level = 1;
        } else if (m_opts->m_jpegQualityLevel < 3) {
            zywrle_level = 3;
        } else if (m_opts->m_jpegQualityLevel < 6) {
            zywrle_level = 2;
        } else {
            zywrle_level = 1;
        }
    } else {
        zywrle_level = 0;
    }
    
    // 选择解压流
    rdr::ZlibInStream* zis = use_zstd ? zstdis : zis;
    
    // 根据色深选择解码函数
    if (!use_zstd) {
        switch (m_myFormat.bitsPerPixel) {
        case 8:
            zrleDecode8NE(x, y, w, h, fis, zis, (rdr::U8*)m_netbuf);
            break;
        case 16:
            if (m_myFormat.greenMax > 0x1F) {
                zrleDecode16LE(x, y, w, h, fis, zis, (rdr::U16*)m_netbuf);
            } else {
                zrleDecode15LE(x, y, w, h, fis, zis, (rdr::U16*)m_netbuf);
            }
            break;
        case 32:
            // 处理24位打包在32位中的情况
            bool fitsInLS3Bytes = 
                (((CARD32)m_myFormat.redMax << m_myFormat.redShift) < (1 << 24) &&
                 ((CARD32)m_myFormat.greenMax << m_myFormat.greenShift) < (1 << 24) &&
                 ((CARD32)m_myFormat.blueMax << m_myFormat.blueShift) < (1 << 24));
            
            bool fitsInMS3Bytes = 
                (m_myFormat.redShift > 7 &&
                 m_myFormat.greenShift > 7 &&
                 m_myFormat.blueShift > 7);
            
            if ((fitsInLS3Bytes && !m_myFormat.bigEndian) ||
                (fitsInMS3Bytes && m_myFormat.bigEndian)) {
                zrleDecode24ALE(x, y, w, h, fis, zis, (rdr::U32*)m_netbuf);
            } else if ((fitsInLS3Bytes && m_myFormat.bigEndian) ||
                       (fitsInMS3Bytes && !m_myFormat.bigEndian)) {
                zrleDecode24BLE(x, y, w, h, fis, zis, (rdr::U32*)m_netbuf);
            } else {
                zrleDecode32LE(x, y, w, h, fis, zis, (rdr::U32*)m_netbuf);
            }
            break;
        }
    }
}
```

#### ZRLE 编码格式
```
+------------+--------+----------+-----------+
| 瓦片 1 RLE | 瓦片 2 | 瓦片 3... | Zlib压缩  |
+------------+--------+----------+-----------+

每个瓦片的RLE编码：
+----------+----------+----------+
| 游程 1   | 游程 2   | 游程 n   |
+----------+----------+----------+

游程格式：
+--------+--------+
| 长度   | 颜色   |
+--------+--------+
```

## 7. 像素格式处理

### 7.1 像素格式转换

```cpp
void ClientConnection::ConvertAll(CARD16 width, CARD16 height, 
                                    CARD16 xx, CARD16 yy,
                                    int bytes_per_pixel,
                                    BYTE* source, BYTE* dest,
                                    int framebufferWidth, 
                                    int framebufferHeight)
{
    // 获取源和目标像素格式的掩码信息
    CARD32 srcRedMask = m_si.format.redMax << m_si.format.redShift;
    CARD32 srcGreenMask = m_si.format.greenMax << m_si.format.greenShift;
    CARD32 srcBlueMask = m_si.format.blueMax << m_si.format.blueShift;
    
    CARD32 dstRedMask = m_myFormat.redMax << m_myFormat.redShift;
    CARD32 dstGreenMask = m_myFormat.greenMax << m_myFormat.greenShift;
    CARD32 dstBlueMask = m_myFormat.blueMax << m_myFormat.blueShift;
    
    for (int y = 0; y < height; y++) {
        BYTE* srcRow = source + y * width * bytes_per_pixel;
        BYTE* dstRow = dest + (yy + y) * framebufferWidth * (m_myFormat.bitsPerPixel / 8)
                      + xx * (m_myFormat.bitsPerPixel / 8);
        
        for (int x = 0; x < width; x++) {
            CARD32 srcPixel = 0;
            memcpy(&srcPixel, srcRow + x * bytes_per_pixel, bytes_per_pixel);
            
            // 提取RGB分量
            CARD8 red = (srcPixel & srcRedMask) >> m_si.format.redShift;
            CARD8 green = (srcPixel & srcGreenMask) >> m_si.format.greenShift;
            CARD8 blue = (srcPixel & srcBlueMask) >> m_si.format.blueShift;
            
            // 映射到目标格式
            CARD32 dstPixel = 
                ((CARD32)red << m_myFormat.redShift) |
                ((CARD32)green << m_myFormat.greenShift) |
                ((CARD32)blue << m_myFormat.blueShift);
            
            memcpy(dstRow + x * (m_myFormat.bitsPerPixel / 8), 
                   &dstPixel, m_myFormat.bitsPerPixel / 8);
        }
    }
}
```

### 9.1 矩形合并优化

```cpp
// 将相邻的小矩形合并成大矩形减少渲染调用
void ClientConnection::MergeRects(RECT* rects, int* count)
{
    if (*count < 2) return;
    
    int merged = 0;
    for (int i = 0; i < *count - 1; i++) {
        if (rects[i].right == rects[i+1].left && 
            rects[i].top == rects[i+1].top &&
            rects[i].bottom == rects[i+1].bottom) {
            // 水平合并
            rects[i].right = rects[i+1].right;
            // 标记为已合并
            rects[i+1].left = rects[i+1].right;
            merged++;
        }
    }
    
    *count -= merged;
}
```
